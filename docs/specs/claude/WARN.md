| 등급 | 뜻 |
| --- | --- |
| 🔴 **불능** | 정상적인 사용 흐름에서 그 기능을 서비스로 제공할 수 없다 |
| 🟠 **조건부 불능** | 흔한 조건(긴 원고, 특정 설정·연동 방식)에서 실패하거나, 보안·운영 사고가 난다 |
| 🟡 **품질 저하** | 기능은 돌아가지만 결과가 틀리거나 중복된다 |
| ⚪ **하지 않음** | 명세 근거가 없어 방침상 하지 않는다 |

| 등급 | 항목 | 안 고치면 벌어지는 일 | 누가 |

### 실제 호출 결과 3 — 다섯 모듈 프롬프트 개선 후 (2026-09-29, `feat/nlcd-rex-prompts`)

`deepseek/deepseek-v4-flash`. 이 단계에서 약 70번 호출(채점기 포함). 테스트 입력은 프롬프트 예시와 겹치지 않게 새로 썼다.

**REX 위반 키워드 → SCDS 룰 검출** (규칙 4개 원고 2개, 라벨 붙인 사건 19개: 위반 10·지킴 9)

| 프롬프트 | 위반 검출 | 지키는 장면 오검출 | 비고 |
| --- | --- | --- | --- |
| 개선 전 | — | — | 키워드에 "주문"·"마법" 같은 일반 단어 |
| 1차(긴 구절) | 0/6 (마법·기사 원고) | 0/5 | 너무 길어 아무것도 안 걸림 |
| 최종(조건어·조사 떼기·양방향 자기 점검) | 마법·기사 3~5/6, 기억 1~4/4 (4번 반복) | 1~2/5, 1~2/4 | 실행마다 뽑히는 동의어가 달라 편차가 크다 |

- 매칭기를 바꿔 본 결과: 어절 사이를 띄워 찾기는 검출 +1·오검출 +1이라 채택하지 않았고, **조사 떼고 비교**는 검출 +1·오검출 0이라 채택했다(`scds/rules.py`).
- 키워드를 8~15개로 늘리면 검출이 5/6·4/4로 올랐지만 호출이 73~128초로 길어지고 한 번은 출력이 잘려 되돌렸다. 같은 시간대에 이전 프롬프트도 36~124초가 걸려, 지연은 제공사 쪽 편차도 크다. `reasoning.effort: low`는 지연·품질 모두 차이가 없어 쓰지 않았다.
- 결론: 키워드 문자열 일치 방식에서는 위반의 약 절반~전부를 잡고, 지키는 장면의 약 1/4이 후보로 걸린다(후보는 AI 분석이 다시 거른다, 아래 SCDS). 표현이 전혀 다른 위반까지 잡으려면 룰 검출 방식 자체를 바꿔야 한다(A2·A14).

**NLCD** — 새 문장 6개: 영향 관계는 모두 이름만, 감정은 행동 단서가 있을 때만 추론("시험 전날 잠을 못 이루고" → 불안, "매일 6시 조깅" → 감정 없음), 같은 말의 카테고리 중복 없음. evals는 의미 채점으로도 2개 실패: ① "자신감 부족"에서 "불안"을 추론하지 않음 ② "솔직하다"를 성격(솔직함)으로 분류(명세는 핵심 가치 "정직"). 둘 다 카테고리 경계 해석 차이라 프롬프트에 정답을 적지 않았다. evals 입력 "그는 다 솔직하계."는 명세 원문의 오타라 빈 결과가 나오기도 한다.

**SCDS AI 분석** — 3개 모두 기대대로(2번 반복): 명백한 위반 → high, 부정문("살해하고 싶었지만 주먹을 거두고") → 충돌 없음, 인질 구출을 위한 제압 → medium. 조언에 원작 지식이 섞이지 않았다.

**AIQ** — 원고에 있는 답은 장·인용으로 근거를 짚고, 없는 정보("어머니")는 "원고에서는 확인되지 않습니다", 선택 구간 질문은 구간 중심으로 답했다.

**SSM** — 3장 원고: 노드 chapter가 1·2·3으로 맞고, 막이 챕터를 넘어 합쳐졌다. 챕터마다 따로 판단해 막이 "발단 → 위기 → 전개"로 되돌아간 적이 있어 앞 단계로 되돌아가는 막은 앞 막에 붙이게 했다.

**evals (의미 채점)** — 6개 중 4개 통과(AIQ·REX·SCDS·SSM). REX는 글자 비교로는 실패였지만 채점기가 "같은 금지 내용"으로 판단했다.
